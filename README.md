## What you can do

- Plan tasks, goals, habits, schedules and countdowns.
- Run focus sessions.
- Track personal finances and budgets.
- Manage notes, documents and private files.
- Create PDFs from text or images, including text labels on images.
- Generate QR codes and scan them using the camera or an image.
- Use unit converters, date tools, calculators and text utilities.
- Choose light, dark or system appearance.

## Install

1. Download the APK from the official website or this repository's release assets.
2. Open the downloaded APK on your Android device.
3. If Android asks, allow installation from the browser or file manager used to open it.
4. Complete installation and open Life Mate.

You can disable that installation permission afterward.

## Update an existing installation

Download the newer official APK and install it over your existing Life Mate installation.

Official updates use the same application identity and signing certificate. An ordinary update is intended to preserve existing local data.

Avoid uninstalling the app when updating: uninstalling can remove its on-device data.

## Privacy

Life Mate is local-first. Core planner, finance, note and vault content stays on your device, and an account is not required.

Network access may be used by configured advertising services and optional app update checking. See the official privacy policy for details.
